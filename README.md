# Pssst landing page

Static website for Pssst, a tiny macOS companion that shows a bot next to your notch when one of your Grok Bot agents is waiting for you.

Plain HTML and CSS, no build step. Served with GitHub Pages from the root of `main`.

- `index.html`: the landing page
- `privacy.html`, `terms.html`: legal pages
- `assets/`: wallpaper and poster previews

The poster previews in `assets/sos/` come from [Study of Space](https://studyofspace.gallery) (MIT license).

Pssst is an independent app, not affiliated with or endorsed by Grok Bot.
